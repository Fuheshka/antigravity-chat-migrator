========================================================================
  Antigravity Chat Migrator - Windows Edition (x64)
========================================================================

EN:
Antigravity Chat Migrator repairs chat history, registers unlinked
workspaces, generates protobuf text annotations, and updates conversation
summaries for Google Antigravity IDE and Antigravity.app.

RU:
Утилита для миграции, исправления истории диалогов, связывания
проектов («Вне проекта» / «Outside of Project»), генерации аннотаций
и обновления кэшей Google Antigravity на Windows.

------------------------------------------------------------------------
[1] ДИСТРИБУТИВЫ И УСТАНОВКА / DISTRIBUTION PACKAGES
------------------------------------------------------------------------
Доступно два варианта поставки для Windows (x64):

1. Установщик Inno Setup (Setup.exe):
   * Файл: Antigravity-Chat-Migrator-Windows-x64-Setup.exe
   * Установка в профиль пользователя (%LOCALAPPDATA%\Programs\...)
     без необходимости повышенных привилегий администратора (UAC-free).
   * Создание ярлыков в меню «Пуск» и на Рабочем столе.
   * Опциональное добавление утилиты 'agy-migrator' в системный PATH.
   * Двуязычный мастер установки (русский и английский языки).

2. Портативный архив (Portable.zip):
   * Файл: Antigravity-Chat-Migrator-Windows-x64-Portable.zip
   * Не требует установки. Распакуйте в любую удобную папку и запускайте.
   * Содержит графический лаунчер, консольную утилиту и скрипт run_fix.bat.

------------------------------------------------------------------------
[2] ГРАФИЧЕСКИЙ ИНТЕРФЕЙС / GUI LAUNCHER
------------------------------------------------------------------------
Запуск: дважды кликните по файлу "Antigravity Chat Migrator.exe"
(или по ярлыку на рабочем столе / в меню «Пуск»).

* Полнофункциональный визуальный интерфейс для управления диалогами:
  - Автоматическое сканирование баз данных и не привязанных диалогов.
  - Связывание проектов («Outside of Project») в один клик.
  - Создание и восстановление резервных копий (бэкапов).
  - Автоматическое определение языка системы с поддержкой RU и EN.
  - Встроенная проверка обновлений через GitHub Releases.

------------------------------------------------------------------------
[3] БЫСТРЫЙ ЗАПУСК / QUICK START (1-CLICK BATCH)
------------------------------------------------------------------------
1. Полностью закройте Antigravity IDE / Antigravity.app перед запуском.
2. Дважды кликните по файлу run_fix.bat.
3. Скрипт выполнит быструю диагностику и предложит применить
   исправления с автоматическим созданием резервной копии.

------------------------------------------------------------------------
[4] РУЧНОЙ ЗАПУСК ИЗ КОМАНДНОЙ СТРОКИ / COMMAND LINE USAGE (CLI)
------------------------------------------------------------------------
Откройте Терминал (cmd.exe или PowerShell) в папке с утилитой
(или из любого места, если agy-migrator добавлен в PATH):

* Просмотр состояния и диалогов (без изменений):
  agy-migrator.exe audit

* Автоматическое исправление и привязка проектов:
  agy-migrator.exe fix

* Безопасная симуляция исправления (dry-run):
  agy-migrator.exe fix --dry-run

* Фоновый режим ожидания выхода из IDE с последующим исправлением:
  agy-migrator.exe watch

* Просмотр созданных резервных копий (снимков):
  agy-migrator.exe rollback --list

* Восстановление из резервной копии при необходимости:
  agy-migrator.exe rollback

* Выбор языка интерфейса (русский / английский):
  agy-migrator.exe --lang ru audit
  agy-migrator.exe --lang en audit

------------------------------------------------------------------------
[5] ПУТИ ДАННЫХ НА WINDOWS / DATA PATHS
------------------------------------------------------------------------
* Базы данных и кэши:  %USERPROFILE%\.gemini\antigravity\
* Реестр проектов:     %USERPROFILE%\.gemini\config\projects\
* Резервные копии:     %USERPROFILE%\.gemini\antigravity\.backups\

------------------------------------------------------------------------
[6] ТРЕБОВАНИЯ К СИСТЕМЕ / SYSTEM REQUIREMENTS
------------------------------------------------------------------------
* Операционная система: Windows 10 / Windows 11 (64-bit).
* Дополнительные зависимости: Не требуются (автономные бинарники).
* Права администратора: Не требуются (работает в профиле пользователя).
